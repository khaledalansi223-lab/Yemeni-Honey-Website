# Yemeni Honey 🍯

A responsive, single-page concept website for a Yemeni honey brand. Designed in Figma and built with plain HTML, CSS and JavaScript.

## Sections
- Home: full-screen hero with a slow zoom effect and a flying bee.
- Products: five honey varieties in a card grid.
- Why Us?: four achievement cards.
- About: brand story with key numbers.
- Reviews: customer testimonials.
- Contact: call-to-action banner and footer.

## Features
- Animated bee that flies across the hero section.
- Sticky navigation bar that changes style on scroll.
- Smooth scrolling to each section.
- Navigation link highlights the section currently in view.
- Elements fade in as you scroll (Intersection Observer).
- Product buttons change color when clicked.
- Mobile menu with a toggle button.
- Responsive layout for desktop, tablet and mobile.
- Respects the "reduce motion" accessibility setting.

## Built with
- HTML5.
- CSS3 (custom properties, Grid, Flexbox, keyframe animations).
- JavaScript (vanilla, no libraries or frameworks).
- Google Fonts: Playfair Display and DM Sans.
- Figma (design).

This is a static front-end website focus on UI/UX design.

## Project structure
index.html   # page structure and content.
style.css    # styling, layout and animations.
script.js    # navigation, scroll effects and interactions.


## Run locally
1. Clone or download this repository.
2. Open the folder in VS Code.
3. Run `index.html` with the Live Server extension.
